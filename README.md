# MediFile

MediFile is a comprehensive patient health information management system that enables the electronic storage, retrieval, and management of patient records. The system includes both web-based and mobile applications for seamless healthcare management.

## Features

- **Patient Records Management**: Secure storage and retrieval of patient health information
- **Appointment Booking**: Schedule and manage medical appointments
- **Pharmacy Module**: Complete e-commerce solution for medication ordering
- **Doctor-Patient Communication**: Real-time messaging system
- **Medical Records**: Comprehensive health history tracking
- **Mobile Application**: React Native app for iOS and Android

## Technology Stack

- **Backend**: Django REST Framework
- **Frontend**: React Native with Expo
- **Database**: SQLite (Development) / PostgreSQL (Production)
- **Authentication**: JWT Token-based authentication

## Getting Started

### Backend Setup
```bash
cd backend/medifile_backend
python manage.py runserver
```

### Frontend Setup
```bash
cd medifile_frontend
npx expo start
```

## Repository Structure

- `backend/` - Django backend application
- `medifile_frontend/` - React Native mobile application
